# TODO API - FELIPE GOMEZ

## 1. Descripcion del proyecto
Este es un proyecto dado el parcial 2 de arquitectura de software en la cual teniamos que crear el todo api usando en este caso FastApi un backend de mucha facilidad y rapidez al crear endpoints el stack practicamente esta hecho por fastApi (Framework), Python (Lenguaje de Programacion) , Insomia ( Para probar endpoints y testeo en general), algunas librerias para el manejo de base de datos e.g (SQLalchemy, Driver-PostgreSQL). La base de datos que utilize fue PostgreSQL porque me parecio robusta, Dockerfile para el manejo de las dependencias y una dockerizacion del sistema. 

## 2. Requisitos del sistema
- Python 3.11++
- Docker y DockerCompose
- Git

## 3. Instalacion y ejecucion
- Docker-compose build --up para la carga de las dependencias y inicializacion del proyecto
